# 腾讯云 COS 存储桶配置指南

## 一、开通腾讯云对象存储服务

1.  **注册/登录腾讯云账号：** 访问 [腾讯云官网](https://cloud.tencent.com/)，注册并登录您的账号。
2.  **开通对象存储服务：** 在腾讯云控制台中，搜索并进入「对象存储 COS」服务页面，按照提示开通服务。

## 二、创建存储桶

1.  **进入存储桶列表：** 在 COS 控制台中，点击左侧导航栏的「存储桶列表」。
2.  **创建存储桶：** 点击「创建存储桶」按钮。
3.  **配置存储桶：**
    *   **名称：** 输入一个唯一的存储桶名称，例如 `linksync-1250000000`。
    *   **所属地域：** 选择一个靠近您或您用户的地域，例如 `ap-beijing`。
    *   **访问权限：** 选择「公有读私有写」。这允许任何人读取您的文件（通过生成的链接），但只有您能上传和删除文件。
    *   **其他设置：** 保持默认设置即可，点击「下一步」并确认创建。

## 三、配置 CORS（跨域资源共享）

为了允许您的网页应用直接向 COS 上传文件，必须配置 CORS。

1.  **进入存储桶详情：** 在存储桶列表中，点击您刚创建的存储桶名称。
2.  **打开安全管理：** 在左侧导航栏中，找到并点击「安全管理」。
3.  **编辑 CORS 配置：**
    *   找到「跨域访问 CORS 设置」，点击「编辑」。
    *   点击「添加规则」。
    *   **来源 Origin：** 输入 `*` 以允许所有域名访问，或输入您的具体网站域名。
    *   **允许 Methods：** 勾选 `GET`, `PUT`, `POST`, `DELETE`, `HEAD`。
    *   **允许 Headers：** 输入 `*`。
    *   **暴露 Headers：** 输入 `ETag`。
    *   点击「保存」。

## 四、获取 API 密钥

您需要使用 API 密钥来在代码中与 COS 进行交互。出于安全考虑，强烈建议使用**临时密钥**。

### 使用临时密钥（推荐）

1.  **创建子账号：** 在腾讯云控制台中，进入「访问管理」->「用户」->「用户列表」，点击「新建用户」。选择「快速创建」，并勾选「编程访问」。
2.  **授权：** 为新创建的子账号关联 `QCloudCOSDataFullControl` 策略，以授予其对 COS 的完全控制权。
3.  **创建临时密钥服务：** 您需要在自己的后端服务器上部署一个服务，用于生成临时密钥。腾讯云提供了多种语言的 SDK 示例。您可以参考 [COS 临时密钥生成](https://cloud.tencent.com/document/product/436/14048) 文档。
4.  **在 LinkSync 中集成：** 修改 `index.html` 中的 `COS_CONFIG`，使其从您的后端服务动态获取临时密钥。

### 使用永久密钥（仅用于测试）

1.  **获取密钥：** 在「访问管理」->「密钥管理」中，您可以查看您的 `SecretId` 和 `SecretKey`。
2.  **填入代码：** 将 `SecretId` 和 `SecretKey` 复制到 `index.html` 文件的 `COS_CONFIG` 对象中。

## 五、修改 LinkSync 配置

1.  **打开 `index.html` 文件：** 找到 `COS_CONFIG` 对象。
2.  **更新配置：**
    *   `Bucket`: 填入您创建的存储桶名称，例如 `linksync-1250000000`。
    *   `Region`: 填入您选择的地域，例如 `ap-beijing`。
    *   `SecretId`, `SecretKey`, `SessionToken`: 根据您选择的是临时密钥还是永久密钥进行填写。

## 六、测试上传

1.  **部署 LinkSync：** 将修改后的 `index.html` 文件部署到您的 Web 服务器上。
2.  **访问应用：** 在浏览器中访问您的应用。
3.  **上传文件：** 尝试上传一个文件。如果配置正确，文件将成功上传到您的腾讯云 COS 存储桶中。您可以在 COS 控制台中查看上传的文件。

## 七、常见问题排查

*   **CORS 错误：** 检查 CORS 配置是否正确。
*   **403 错误：** 检查 API 密钥是否有效，以及是否具有正确的权限。
*   **上传失败：** 检查网络连接，并确认存储桶的访问权限为「公有读私有写」。

如果您在配置过程中遇到任何问题，请参考 [腾讯云对象存储官方文档](https://cloud.tencent.com/document/product/436)，或随时向我咨询。
