# 知空空的空想世界

一个个人主页网站：基于 Vite 构建的现代静态前台 + 腾讯云 EdgeOne Pages 上的无服务器内容管理后台（CMS）。
项目预览：https://www.chikuu.top/

- 前台：响应式个人主页，含用户信息、地图、粉丝数据、音乐播放器、视频作品、联系方式等卡片，支持拖拽排序与深浅主题切换。
- 后台：访问 `/admin` 即可在线管理全部站点内容（网站信息、备案信息、文字内容、B 站视频同步等），数据存于 EdgeOne KV，带认证、版本回溯与操作日志，无需自建服务器。

详细的代码级变更历史见 [CHANGELOG.md](./CHANGELOG.md)。

## 功能特性

### 前台站点

- 🎨 响应式设计，适配各种设备屏幕
- 🌓 深色/浅色主题切换，支持系统主题自动检测
- 🔄 卡片拖拽排序，布局可自定义
- 🗺️ 高德地图展示当前位置
- 🎵 网易云音乐播放器
- 📊 各平台粉丝数据实时展示
- 🎥 视频作品展示（首页精选 4 个 + 「更多视频」弹窗全量列表）
- 📱 联系方式整合
- 🛡️ 动态配置三层兜底：远程配置 -> localStorage 缓存 -> 打包内静态配置，接口故障站点照常运行

### 内容管理后台（CMS）

- 🔐 单管理员认证：PBKDF2 哈希存储、登录失败 5 次锁定 15 分钟、7 天会话、CSRF 防护
- 🖊️ 网站信息 / 备案信息 / 文字内容（富文本 + 源码双模式）在线编辑，图片支持 COS 直传
- 🔄 B 站视频自动同步（定时 + 手动），条目可置顶 / 隐藏 / 编辑 / 标合作
- ⏪ 版本回溯：每次保存生成快照（保留 50 个），一键非破坏性回滚
- 📜 操作日志：登录 / 保存 / 回滚 / 同步等全记录（保留 500 条，含 IP）
- 🔒 下载页安全化：服务端签名短时效预签名链接，密钥不再暴露到前端

## 快速开始（本地开发）

环境要求：Node.js >= 18（同步引擎测试依赖原生 fetch / crypto）。

```bash
npm install              # 安装依赖
npm run dev              # 启动开发服务器（前台 + /admin）
npm run build            # 构建产出 dist/
npm run preview          # 预览构建结果
node test-sync-live.mjs  # B 站同步引擎真实联调测试（内存 KV 模拟，16 项断言）
```

前台与后台页面均为纯前端，可直接本地开发调试；边缘函数需 EdgeOne 环境运行（可参考 `edgeone pages dev` 本地模拟，或直接部署后做冒烟测试）。同步引擎为纯 Web API 实现，`test-sync-live.mjs` 在 Node 中即可完成真实联调验证，含三组用例：成功同步、覆盖合并（置顶/隐藏/改标题）、全链路失败容错（原数据保留）。

## 内容管理后台（CMS）

### 架构总览

```
前台静态站点（Vite 构建）
        │  启动时拉取 GET /api/config
        │  （localStorage 缓存 + 打包内静态配置双兜底，接口故障站点照常运行）
        ▼
EdgeOne Pages 边缘函数（仓库 functions/ 目录，文件路由）
        ▼
EdgeOne KV 存储（运行时变量名 CMS_KV）
```

**访问方式**：部署完成后访问 `https://<你的域名>/admin`，使用环境变量中配置的账号密码登录。

### 功能模块

| 模块 | 功能 |
| --- | --- |
| 仪表盘 | 站点内容状态概览（视频总数 / 上次同步 / 版本总数 / 日志总数）与最近版本、最近操作 |
| 网站信息 | 标题、meta 描述、favicon、logo，支持上传图片到 COS |
| 备案信息 | ICP 备案号（默认链工信部）、公安备案、自定义页脚文字、启用开关（控制前台页脚渲染） |
| 文字内容 | 个人信息（昵称 / 头衔 / 简介 / 头像 / 了解更多长文）、社交链接、联系方式、音乐歌单；HTML 字段支持富文本编辑（wangEditor）与源码模式切换、Tailwind 样式实时预览 |
| 视频管理 | 与 B 站空间同步（默认 mid=28826850，可改）；条目可置顶 / 隐藏 / 编辑 / 标合作（同步条目与手动条目均支持）；手动添加的条目同步时保留 |

| 操作日志 | 登录 / 登出 / 保存 / 回滚 / 同步 / 改密全记录（保留 500 条，含 IP） |

### 部署配置（一次性）

CMS 支持**两种存储后端自动切换**，优先级：EdgeOne KV > 腾讯云 COS。KV 申请过了就用 KV（性能更好），没过就用 COS（你已有的桶直接复用），代码无需改动，绑定环境变量即自动切换。

所有 CMS 数据在 COS 中统一放在 `cms/` 前缀下，不与上传文件等业务数据混淆。

#### 1. 配置存储（二选一或都配）

**方案 A：EdgeOne KV（推荐，性能更好）**

在 EdgeOne Pages 控制台：开通 KV 存储 -> 创建 KV 命名空间 -> 绑定到本项目。**运行时变量名必须填 `CMS_KV`**。

**方案 B：腾讯云 COS（KV 申请没过时直接用）**

无需额外操作，配置好下面的 `COS_SECRET_ID` / `COS_SECRET_KEY` 即可，系统自动检测并使用。所有 CMS 数据存放在桶内 `cms/` 目录下。

> 💡 两种可以同时配置：KV 绑定时自动用 KV，KV 解绑时自动降级到 COS，可随时切换（注意切换后数据不互通，两套独立）。

#### 2. 配置环境变量

EdgeOne Pages 项目设置 -> 环境变量，添加：

| 变量名 | 必填 | 说明 |
| --- | --- | --- |
| `ADMIN_USERNAME` | ✅ | 管理员用户名 |
| `ADMIN_INIT_PASSWORD` | ✅ | 初始密码（仅首次登录时写入存储哈希，之后以存储为准，可在后台修改密码） |
| `CRON_KEY` | ✅ | 定时同步密钥（随机长字符串） |
| `COS_SECRET_ID` | 方案 B 必填 | 腾讯云 API 密钥 SecretId |
| `COS_SECRET_KEY` | 方案 B 必填 | 腾讯云 API 密钥 SecretKey |
| `COS_BUCKET` | 可选 | COS 存储桶名，默认 `chikuu-1252656027` |
| `COS_REGION` | 可选 | COS 地域，默认 `ap-nanjing` |

> 💡 COS 密钥建议在腾讯云「访问管理」新建一对仅授权该 COS 桶的子账号密钥。

#### 3. 配置定时同步

编辑仓库根目录的 `edgeone.json`，把 `schedules[0].path` 中的占位文本替换为你的 CRON_KEY 值：

```json
{
  "schedules": [
    {
      "name": "daily-video-sync",
      "cron": "0 9 * * *",
      "path": "/api/cron/sync?key=<你的CRON_KEY值>"
    }
  ]
}
```

默认每天 9 点同步一次，可自行调整 cron 表达式。定时任务有 **2 小时节流**：距上次成功同步不足 2 小时（含手动触发的成功同步）时，定时触发会自动跳过。

#### 4. 重新部署

提交代码并触发部署，使环境变量与定时任务配置生效。

#### 5. 腾讯云控制台安全收尾（针对旧密钥泄露，严格按顺序）

1. 确认 EdgeOne 新环境变量已部署完成，且下载页、后台上传功能均正常；
2. 访问腾讯云「访问管理 -> API 密钥管理」，禁用并删除旧的泄露密钥；
3. 到 COS 桶删除根目录下的 `config-v1.js` 旧副本（内含明文密钥）。

#### 6. 核对 COS CORS（图片上传直传需要）

COS 桶 -> 跨域访问 CORS 设置，确认：

- 允许来源包含你的站点域名；
- 允许方法包含 `PUT`（以及 `GET`、`HEAD`）。

若原先 linksync 上传已配置过 CORS，则无需改动。

### 后台使用指引

登录 `/admin` 后按左侧导航操作，各页面用途见上文「功能模块」表。注意事项：

- **富文本模式切换**：从源码切到富文本时 wangEditor 会重排 HTML，页面会先弹出确认；保存前建议核对预览效果。
- **回滚**：回滚入口带红色警示，确认后才会执行；回滚本身也会生成一个新版本，随时可以再次回滚，不会丢失数据。
- **视频同步**：同步需依次请求多个外部接口（含风控重试），可能需要约 30 秒，请耐心等待结果提示。
- **配置生效延迟**：后台保存后前台约 1-2 分钟生效（KV 最终一致性 ≤60 秒 + 前台接口边缘缓存 60 秒），属正常现象。

### 视频同步机制

**数据源容错链**（依次尝试，任一成功即用；全部失败时保留旧数据，不会清空）：

1. B 站 wbi 签名接口（`x/space/wbi/arc/search`）
2. B 站旧接口（`x/space/arc/search`）
3. RSSHub 公共实例（双实例逐个尝试）

**B 站风控应对**：B 站对无 cookie 的服务端请求有概率风控（HTTP 412 / 错误码 -352 / -799）。同步引擎会自动完成身份构建（`finger/spi` 取 buvid 指纹 + HMAC-SHA256 签名换取 `bili_ticket` 访问令牌），并在风控拦截时间隔 2 秒重试（最多 4 次），实测可稳定通过。同步成功后自动生成版本快照，同步到脏数据可从版本历史回滚。

**数据规范化与容错**：单条字段异常跳过该条而非整体失败、封面协议补全（`//` -> `https://`）、时间戳统一毫秒、标题/描述长度截断；返回列表为空视为该源失败，继续尝试下一源。

### 安全机制

- **认证**：单管理员，PBKDF2（随机盐）哈希存储，初始密码经环境变量种子化；登录失败 5 次锁 15 分钟；会话 token 经 HttpOnly + Secure + SameSite=Strict Cookie 下发，有效期 7 天。
- **CSRF**：全部写接口（含登录）校验 `X-Requested-With` 请求头，跨站表单无法构造。
- **下载页**：原前端明文密钥直连 COS 的方式已移除（`public/config-v1.js` 已删除），列文件走 `GET /api/downloads`，下载走短时效预签名链接 `GET /api/downloads/url?key=xxx`（10 分钟有效，仅 `uploads/` 前缀，含路径穿越防护）。COS 密钥仅保存在 EdgeOne 环境变量。
- **输出安全**：备案页脚等前台渲染使用 DOM API 构建，避免 HTML 注入。

## 配置说明

站点内容分为两层：

- **在线配置（推荐）**：通过内容管理后台（`/admin`）修改，保存后写入 EdgeOne KV 存储，前台启动时通过 `GET /api/config` 拉取。
- **静态默认配置**：打包在前台内的 `src/js/config.js`。远程配置接口故障时，前台会依次回退到 localStorage 缓存的最近一次配置、该静态配置，站点照常运行。

静态默认配置中可修改：网站基本信息、用户信息、社交媒体链接、视频作品列表、联系方式文本、音乐播放器配置（作为兜底数据，平时无需改动）。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 访问 `/api/*` 返回 `NO_STORAGE` | 未配置任何可用存储：要么绑定 EdgeOne KV（变量名 `CMS_KV`），要么配置 `COS_SECRET_ID` / `COS_SECRET_KEY` 环境变量 |
| 视频同步失败，提示 -352 / -412 | B 站风控概率拦截：引擎已内置身份伪装与 4 次间隔重试，偶发失败时稍后重试即可；系统会自动降级到 RSSHub 兜底，全部失败则保留旧数据 |
| 部署后 `/api/*` 路由 404 | 确认 `functions/` 目录已随仓库部署；若平台要求目录名为 `edge-functions/`，把 `functions/` 整体改名即可（代码内部相对导入不受影响） |
| 下载页提示 `COS_NOT_CONFIGURED` | 环境变量未配置 `COS_SECRET_ID` / `COS_SECRET_KEY` |
| 手动同步后定时任务没执行 | 正常现象：2 小时节流生效，距上次成功同步不足 2 小时的定时触发会跳过 |
| 前台改动未立即生效 | 正常现象，等待 1-2 分钟缓存过期 |
| KV 申请下来后怎么从 COS 切到 KV | 绑定 `CMS_KV` 变量后重新部署即自动切换。切换后数据为空（两套存储独立），需重新录入或手动导出 JSON 迁移 |
| 忘记密码 | 删除存储中的 `admin_user` 键（KV 模式删 key，COS 模式删 `cms/admin_user` 对象），再用环境变量中的初始密码重新登录 |

## 部署说明

本项目面向腾讯云 EdgeOne Pages 部署，依赖其边缘函数、KV 存储与定时任务能力，`/admin` 后台与 `/api/*` 接口仅在该平台可用，完整部署步骤见上文「内容管理后台（CMS）-> 部署配置（一次性）」。

若仅部署前台静态页面（GitHub Pages / Vercel / Netlify / 云服务器等），后台与动态配置接口不可用，前台会使用 localStorage 缓存或打包内静态配置兜底，站点仍可正常访问。
